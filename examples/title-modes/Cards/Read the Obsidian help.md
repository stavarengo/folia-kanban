Read the setup guidance before writing the board instructions.

The tile and panel header show the title as a clickable link. The file uses the link's readable label, and `title:` keeps the full Markdown. Both boards show the same title because `title:` is read before either the file name or a heading. Change Title in the panel to `Read the Obsidian help` without Markdown and the property disappears, since the file name can hold that title exactly.
