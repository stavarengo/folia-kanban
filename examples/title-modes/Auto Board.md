# Auto Board

One of three boards over the same three cards, differing only in the `card-title` property above. `auto` is the default: a card whose file name reads as a slug takes its title from the first heading that reads as a real title; every other card shows its file name. Open the other two board notes in this folder to see the same cards under `heading` and `filename`.
