# Example Board

A minimal board to try the plugin. With the repository open as a vault, focus this note and run **“Open Folia Kanban board”**. Cards live in `examples/basic/Cards` — the `card-folder`, written here as `./Cards` so it is resolved **relative to this note**, which means this whole folder can be copied anywhere and the board still finds its cards. Columns are the `columns` list above. For a board that exercises every feature, see `examples/feature-showcase/`.
