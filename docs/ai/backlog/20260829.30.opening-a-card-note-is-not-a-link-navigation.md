# Opening a card note is not a link navigation, so modifier keys and hover previews do nothing

## What is asked

Findings 05-02 and 05-03 of the audit of 2026-08-29 ([section 05](../reports/20260829.what-obsidian-already-provides/05.workspace-views-commands-and-settings.md), cross-referenced as 03-02 and 03-03 in [section 03](../reports/20260829.what-obsidian-already-provides/03.editor-rendering-search-and-dates.md)). Both are listed among the report's top findings, and both are user-visible.

## Current behaviour

Every "Open note" affordance in the board ends at `openCard` (`src/obsidian/vaultRepo.ts:658`), which is `this.app.workspace.getLeaf(false).openFile(...)` — always the current tab. The call sites drop the click event that would say otherwise: `src/ui/CardItem.tsx:394` calls `actions.openNote(notePath)` with no event. So Ctrl or Cmd click, middle click and the modifier combinations that open a split or a new window everywhere else in Obsidian all do the same thing here: they replace the current tab. Obsidian publishes `Keymap.isModEvent` for exactly this, and `getLeaf` accepts what it returns.

Separately, the detail panel renders comments and descriptions through `MarkdownRenderer.render` with a real `sourcePath` (`renderMarkdown`, `src/obsidian/vaultRepo.ts:662`), so those internal links are live — but the view is never registered as a hover-link source, so hovering one shows no page preview, which is the behaviour every other link in the app has.

Neither is a one-liner. The click-to-leaf path runs through five signatures (the board-actions context at `src/ui/context.ts:181`, the model port at `src/model/repo.ts:136`, the adapter, the fake repository and the call sites), because `src/ui/**` cannot import `obsidian` and so cannot read a modifier itself. The hover preview is two halves, and one half does nothing without the other: registering the source, and triggering the `hover-link` event from the rendered links.

## How to observe

Ctrl or Cmd click a card's "Open note" affordance and watch it replace the current tab instead of opening a new one. Then hover an internal link inside a card's rendered description and compare against hovering the same link in an editor pane.

## Expected outcome

Opening a card behaves like following a link in Obsidian, and links Folia renders behave like links Obsidian renders.
