# `src/main.ts` is a thousand lines, against a review checklist item the repository already agrees with in writing

## What is asked

Finding 07-05 of the audit of 2026-08-29 ([section 07](../reports/20260829.what-obsidian-already-provides/07.guidelines-mcp-build-and-the-rest.md)). Unlike most of that section, this is not a substitution for an Obsidian facility: it is a structural item the community review checklist names outright.

## Current behaviour

`src/main.ts` is 1020 lines holding the plugin class, the `setViewState` patch, the board-setup commands, the whole settings tab in both of its renderings, and the MCP wiring. `eslint.config.mjs:142-163` switches `max-lines`, `max-lines-per-function` and `complexity` off for this file and fourteen others, under `tracking/waivers/0004-legacy-file-size-complexity.md`, which is active, has a plan and expires on 2026-12-31. Every new file stays fully gated, so this is acknowledged debt with a date on it rather than an unnoticed drift.

Several other entries raised from the same audit land in this file — the prototype patch and the undeclared `popstate` field, the four workspace conventions, the settings tab's two renderings — and they are easier or harder depending on whether this happens first.

## How to observe

`wc -l src/main.ts`, then read the waiver and its expiry.

## Expected outcome

The waiver's plan is carried out or deliberately renewed before it expires, rather than expiring by default.
