# A vault set to Markdown links still gets wikilinks from Folia

## What is asked

Obsidian has a vault-wide setting for how links are written: `useMarkdownLinks` (Settings → Files and links → "Use [[Wikilinks]]"). With it off, every link Obsidian writes is `[Child](Cards/Child.md)`. Folia writes `[[Child]]` either way, and reads nothing else.

Left over from findings 04-02 and 04-03 of the audit of 2026-08-29 ([section 04](../reports/20260829.what-obsidian-already-provides/04.vault-files-and-metadata.md)). The entry that closed them fixed which note a link binds to and made every link Folia writes follow the vault's path style; it deliberately stopped short of the bracket style, because that half cannot ship without the read side below.

## Current behaviour

`src/obsidian/vaultRepo.ts` (`linkTextTo`) asks `FileManager.generateMarkdownLink` for the link text and keeps only the part inside `[[…]]`, falling back to the full vault path when the answer is not a wikilink at all. So a vault set to Markdown links gets a wikilink from Folia — correct, resolvable, and not the shape the rest of that vault uses.

Emitting the vault's own shape means reading it too, and that is the size of the job: `src/model/card.ts` recognizes a subcard line by `[[…]]` (`pendingSubcardLinks`, the `## Subtasks` parse), `src/model/relationships.ts` reads a stored relationship with `WIKILINK_RE`, `src/mcp/tool.ts` resolves a card reference by link name, and every one of them would have to accept `[text](path.md)` — with the URL-encoding a Markdown link carries — without breaking a note already written the other way.

## How to observe

In a vault with "Use [[Wikilinks]]" switched off, add a subcard from a card's detail panel and open the parent note: the checklist line reads `- [ ] [[Child]]` where every other link in that vault reads `[Child](Cards/Child.md)`. Write the Markdown form into the checklist by hand and the board stops seeing a subcard at all.

## Expected outcome

Links Folia writes take the shape the vault is configured for, and a note written in that shape reads back as the same board.
