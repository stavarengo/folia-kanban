# The `--folia-*` token layer is a second design system standing beside the one Obsidian ships

## What is asked

The audit of 2026-08-29 ([section 02](../reports/20260829.what-obsidian-already-provides/02.styling-theme-and-design-language.md)) counted one decision out, one declaration at a time, across eleven findings: 02-11, 02-12, 02-13, 02-15, 02-21, 02-22, 02-23, 02-26, 02-27, 02-28 and 02-44. Folia did not skip having a design system; it built a complete second one, with a JSON source of truth under `tokens/`, generation and drift scripts and a raw-value audit, in the space where Obsidian's foundations already live.

## Current behaviour

Each rung of the ladder, with its finding:

- A radius ladder no theme can reach — five `--folia-r-*` values consumed by nearly every surface, beside Obsidian's `--radius-s/m/l` (02-11).
- A nine-rung font-size scale (10px to 16px, including half-pixel rungs) shadowing Obsidian's four UI sizes, consumed by 62 declarations (02-21); two hard-coded font weights beside the app's named weight scale, used 24 times (02-22); thirteen line heights written as literals in five values, six of which already match the app's (02-23).
- Around 140 hard-coded gaps and paddings that land exactly on Obsidian's 4-pixel grid without using it, out of 233 counted (02-12); 31 hand-written `1px solid` borders plus four dashed ones where a border-width variable exists (02-13); control heights invented rather than taken from `--input-height` (02-15).
- Five elevation shadows over literal black, tuned for dark mode and applied unchanged in light, with the scrim beside them (02-26); one animation duration escaping the motion tokens (02-27).
- Thirteen `cursor: pointer` declarations against Obsidian's explicit convention not to use one, which finding 02-28 calls the single most visible "this is not part of the app" tell in the stylesheet.
- Two inline styles carrying a literal colour where the other eleven inline styles are values only the runtime can know (02-44).

What makes this hard to move rather than merely tedious is named in the findings: several of these change the board's density or its corners by a couple of pixels everywhere, and there is no visual harness — `tracking/waivers/0003-visual-regression-automation.md` records that absence. The parts with no Obsidian equivalent are named too (10px and 11px small print, the in-board z-index rungs, the drag ghosts).

## How to observe

Change Obsidian's own interface font size or a theme's radius and watch the board not respond. `pnpm check:tokens` shows what the token layer currently asserts about itself, and none of those assertions compares a token to the app's equivalent.

## Expected outcome

A decision about what the `--folia-*` layer is for: a translation layer that maps onto Obsidian's foundations wherever one exists, keeping only the rungs the app has no answer for, or a deliberately independent product design system whose independence is written down. The findings identify the free half (weights, line heights that already match, borders, the shadow split by theme, the cursor convention) and the half that is a visual redesign; either way the answer is one position, not eleven.
