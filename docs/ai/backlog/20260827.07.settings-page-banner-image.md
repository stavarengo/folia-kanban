# Can the settings page carry a banner image?

## What is asked

Rafa asked on 2026-08-27, while shaping what became the settings-UI rework (entry 20260827.05, done on 2026-08-29), to investigate whether the plugin's settings tab can show a horizontal banner image with the Folia Kanban logo as its header.

## Current state

`KanbanSettingTab.display()` (`src/main.ts`) empties `containerEl` and renders `Setting` rows only; nothing in the tab is an image today, and the plugin ships no image assets besides a README screenshot. A banner has two open questions before it can be built: whether the Obsidian settings surface and the community-plugin guidelines allow a decorative image in a plugin's tab (and how, given the tab is meant to stay a native `PluginSettingTab`), and how the image gets to the user, since a released plugin is `main.js`, `styles.css` and `manifest.json` and a bitmap would have to be inlined, drawn as SVG, or fetched.

## Dependencies

This is blocked by the visual identity (20260827.06): the banner's content, colours and shapes come from it, so nothing can be drawn before that exists. It leaned on the settings-UI redesign, which has since landed: the tab is now a handful of headed sections built from `SETTING_GROUPS` in `src/settingsLayout.ts` and drawn on both rendering paths by `src/settingsDefinitions.ts` and `src/main.ts`, so a banner has a settled layout to be placed into rather than a flat list.

## Expected outcome

An answer to "can we, and how", with the constraints found (API, guidelines, asset delivery, both Obsidian themes, mobile), and then, once the identity exists and the tab has its new shape, the banner itself at the top of the settings tab.
