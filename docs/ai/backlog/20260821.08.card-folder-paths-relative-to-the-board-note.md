# Let `card-folder` be a path relative to the board note, not only to the vault root

## What is asked

`card-folder` is resolved against the vault root today, and that stays. The addition is a fallback: when the path cannot be found from the root, try it relative to the note the property is written in.

Relative means genuinely relative, `./` and `..` included, so a board note sitting in a project folder can point at `./issues` or `../shared/cards` without knowing or repeating its own location in the vault. That keeps a self-contained project folder portable: move it, and the board still finds its cards.

## What already exists

Resolution is string handling, not path handling. `VaultRepository.readConfig` (in `vaultRepo.ts`) now normalizes the configured value once — trimming a trailing slash (`cardFolderPath`, in `board.ts`) and running it through Obsidian's `normalizePath` — and every consumer (`loadBoard`'s card-selection prefix, `deriveContext`'s context-subfolder prefix, `loadContexts`, `ensureFolder`, `uniquePath`) reads that single already-normalized `BoardConfig.cardFolder` value, so this item's "whatever a relative path resolves to has to be the single value all of them see" concern already has one obvious place to land: `readConfig`. None of that resolution makes sense of a `..` segment yet; a relative or escaping path would simply match nothing.

Obsidian's `normalizePath` is already imported and used in `readConfig`/`uniquePath`, but the API reference documents only its signature, not its behaviour — whether it resolves `..` segments or merely tidies slashes has to be established empirically before anything leans on it.

## Undecided

- Which wins when a path resolves under both readings — the request says vault root first, board-note-relative as fallback, and that ordering should be confirmed as deliberate.
- Whether the resolved path is what gets written back and shown anywhere the configured value is displayed, or whether the raw property text stays authoritative.
- What a path that escapes the vault entirely should do.
- Whether a board note that moves should keep working silently, given that a relative path's meaning travels with the note while an absolute one does not.
