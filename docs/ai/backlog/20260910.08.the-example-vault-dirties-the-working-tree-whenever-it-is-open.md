# The example vault dirties the working tree whenever it is open

## What happens

`examples/.obsidian/workspace.json` is tracked by git and Obsidian rewrites it every time the example vault is opened, resized or navigated. The working tree is therefore dirty almost whenever Obsidian is open, and every session that works in the vault has to remember to leave that file out of its commits.

Found on 2026-09-10 while reading the release path; the release half of that finding is gone, since releases are cut on a runner with a clean checkout and `.release-it.json` no longer switches its clean-tree check off.

## How to observe

Open the example vault in Obsidian, move a pane, and run `git status`.

## Expected outcome

Opening the example vault does not dirty the working tree, and no session has to remember a file that must never be staged.
