# Copy a card's path in several useful forms from its mouse menu

## What is asked

Using the auxiliary mouse click on a card inside a Folia board should expose four copy actions:

- Copy path
- Copy path relative to vault
- Copy path relative to board folder
- Copy base name

The four actions matter because the useful representation depends on where the copied value will be pasted. In particular, the path relative to the board's folder is distinct from the vault-relative path when the board note lives below the vault root.

## Current behaviour

A card already has a mouse context menu for card actions, but it offers no way to copy the card file's path or base name. Getting any of these values currently requires finding the note elsewhere or reconstructing the value by hand.

## Expected outcome

An auxiliary mouse click on a card provides the four requested copy options. Each option puts the corresponding representation of that card file into the clipboard, including a board-folder-relative path that is calculated from the folder containing the active board note.
