# Make the community-portal review fully green

## Problem

The Obsidian community-plugin portal's review for this plugin has shown warnings, for example a Stylelint browser-feature warning on `text-decoration`.

A local reproduction of the portal's scanner now exists (a worker under `scripts/`, wired into `pnpm verify` as `obsidian-scan:check`, landed 2026-08-26), so warnings can be caught before a release ships. But nothing yet guarantees that every future release actually gets checked, and the public portal page itself has not been confirmed clean since these fixes landed.

## Expected outcome

The public page at `community.obsidian.md/plugins/folia-kanban` shows the latest release with a clean Review rating, with no login needed to see that. That stays true release after release, not just for one snapshot in time.

## Suggested order

1. Adopt the official `obsidianmd/obsidian-workflows` action (see [20260826.02](./20260826.02.adopt-official-obsidian-workflows-action.md)) so every release is checked against the same rules the portal uses before it ships, not just via the local worker.
2. Only after that is in place, if the portal page still lags behind the latest release or disagrees with what the local scan and the official action both say, that is the point where asking Obsidian for an on-demand refresh (see [20260826.01](./20260826.01.no-on-demand-refresh-for-community-plugin-portal.md)) becomes the relevant next step — not before, since there is no point escalating a staleness question while the release pipeline itself might still be the source of the warnings.

## How to verify

- Visit `https://community.obsidian.md/plugins/folia-kanban` (no login required) and confirm it shows the current released version with a clean Review rating.
- The detailed warning list (if any) is only visible on the maintainer's own account page on the portal, not on the public listing.
